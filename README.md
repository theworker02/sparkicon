# sparkicon

Spark filesystem icon paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/sparkicon/

## Install / run

```bash
git clone https://github.com/theworker02/sparkicon.git
cd sparkicon
node src/cli.js
node --test
```
